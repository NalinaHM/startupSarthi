## 🎯 The Problem & Our Solution

- **The Problem**: Millions of aspiring founders and small-business creators across Tier 1, 2, and rural India have valuable business ideas but fail to start due to **lack of starting capital**, complex **bank loan paperwork**, and fear of **debt traps**.
- **Our Solution**: **StartupSarthi** transforms any idea into an actionable, low-capital launch plan. It matches official government loans and grants (Mudra, PMEGP, SISFS), drafts a bank-ready Detailed Project Report (DPR), and provides an interactive AI Financial Assistant to guide founders step-by-step.

---

## ✨ Key Feature Modules

### 1. 🤖 AI Financial Assistant & 24/7 Mentor
- **Context-Aware Advisory**: Automatically references your currently analyzed startup idea, sector, location, starting capital, and matched loan schemes.
- **1-Tap Quick-Question Chips**: Instant answers for questions like:
  - *“How do I get a Mudra loan if the bank manager asks for collateral?”*
  - *“How can I launch with less than ₹5,000?”*
  - *“How do I claim a 35% PMEGP government subsidy?”*
  - *“What will the bank manager ask during my loan interview?”*
- **Rich Actionable Cards**: Provides clear practical advice, an interactive task checklist, financial math (margins, working capital), applicable schemes, and founder golden rules.
- **Persistent Offline History**: Past questions and answers remain stored on your device.

### 2. 💸 Low & Zero-Capital Launch Planner
- **Starting Capital Input**: Select your real savings tier (`₹0`, `< ₹25,000`, `₹25k–₹1L`, `₹1L–₹5L`, `₹5L+`).
- **Lean MVP Budget Breakdown**: Distinguishes between **Must-Have** expenses and items that **Can Wait**.
- **Zero-Cost Bootstrap Shortcuts**: Guidance on using WhatsApp Business, UPI QR codes, free Canva assets, and zero-fee Udyam registration to avoid unnecessary early spend.
- **First 30 Days Action Roadmap**: Week-by-week zero-debt plan focused on pre-selling and early cash flow.

### 3. 🧮 Offline Smart Govt Subsidy & EMI Calculator
- **100% Offline Support**: Works instantly without calling any external API.
- **PMEGP Subsidy Matcher (15%–35%)**:
  | Category | Urban Area | Rural Area (+10% Bonus) |
  | :--- | :---: | :---: |
  | **General** | **15% Subsidy** (10% Own Margin) | **25% Subsidy** (10% Own Margin) |
  | **Special (Women / SC-ST / OBC / Divyang)** | **25% Subsidy** (5% Own Margin) | **35% Subsidy** (5% Own Margin) |
- **Mudra Loan Tiers**:
  - 🟢 **Shishu**: Up to ₹50,000 (Micro seed & equipment)
  - 🔵 **Kishore**: ₹50,000 to ₹5 Lakhs (Working capital & tooling)
  - 🟡 **Tarun**: ₹5 Lakhs to ₹10 Lakhs (Machinery & business expansion)
  - 🟣 **Tarun Plus**: Up to ₹20 Lakhs (Established enterprise scaling)
- **Live EMI Calculator**: Computes monthly installments and net loan required after subsidy credit.

### 4. 📄 Bank-Ready Detailed Project Report (DPR) Generator
- **Customizable Promoter Details**: Enter applicant name, enterprise name, unit address, and phone number.
- **White-Paper Loan Document**:
  - Cost of Project (Fixed Capital vs. Working Capital)
  - Means of Finance (Own Contribution, Govt Subsidy, Bank Loan)
  - 12-Month Projected Sales, Expenses, and Net Surplus
  - Loan Repayment Viability & DSCR Coverage
  - Official Applicant Signature & Declaration Block
- **One-Click Print / PDF Export**: Formatted specifically for bank officers and loan committees.

### 5. 🏛️ Verified Indian Government Schemes Matrix
- Comprehensive directory of verified schemes: **PM Mudra Yojana (PMMY)**, **PMEGP**, **Stand-Up India**, **PM SVANidhi**, **Startup India Seed Fund Scheme (SISFS)**, and **PM Vishwakarma**.
- Direct links to official portals (`JanSamarth.in`, `KVIC`, `StartupIndia`).
- Interactive document checklists (Aadhaar, PAN, Udyam, 6-Month Bank Statements, Quotations) auto-saved to device storage.

### 6. 🌐 Multilingual UI & AI Engine
- Switch seamlessly between:
  - 🇬🇧 **English (`EN`)**
  - 🇮🇳 **हिन्दी (`हिं`)**
  - 🇮🇳 **ಕನ್ನಡ (`ಕ`)**
- Both the app interface and AI-generated blueprints, financial advice, and checklists render in your selected language.

### 7. 📱 Two-Way Publishing (PWA + Native Android App)
- **Installable PWA**: Works on Chrome, Edge, and Safari; install directly to your home screen with offline caching.
- **Android App (Capacitor)**: Full native Android project (`com.nalinahm.startupsarthi`) with launcher icons for all screen densities.
- **Automated Cloud APK Builds**: GitHub Actions builds a signed `.apk` on every push—no Android Studio setup required.

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 19, Vite 8, JavaScript (ES6+)
- **Mobile Runtime**: Capacitor 7 (Android Native Platform)
- **Styling**: Responsive Modern Dark Glassmorphism CSS, Print Media Styles (`@media print`)
- **AI Core**: Google Gemini AI (`gemini-2.5-flash`) via structured JSON schema
- **Backend Proxy**: Vercel Serverless Function (`api/analyze.js`) protecting `GEMINI_API_KEY`
- **CI/CD**: GitHub Actions (`.github/workflows/build-android.yml`)

## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm
- Google Gemini API Key ([Get a free key at Google AI Studio](https://aistudio.google.com/app/apikey))

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/NalinaHM/startupSarthi.git
cd startupSarthi

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env
# Open .env and add your GEMINI_API_KEY=your_key_here

# 4. Start the local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

## 📲 How to Download & Build the Android App

### Option A: Direct Cloud Download via GitHub Actions (Easiest)
1. Open [**github.com/NalinaHM/startupSarthi/actions**](https://github.com/NalinaHM/startupSarthi/actions).
2. Click on the latest run of **Build StartupSarthi Android APK**.
3. Under **Artifacts** at the bottom, click **`StartupSarthi-Android-APK`** to download your installable `.apk`.
4. Open the `.apk` on any Android smartphone and tap **Install**!

### Option B: Local Android Studio Build
```bash
# Build the production web assets and sync with native Android
npm run android:sync

# Open the project in Android Studio
npm run android:open
```
Inside Android Studio:
- Select **Build → Build Bundle(s) / APK(s) → Build APK(s)** for testing.
- Select **Build → Generate Signed Bundle / APK → Android App Bundle (`.aab`)** for Google Play Store publishing.

---

## 🌐 Deploying Live to Vercel (Free — 3 Minutes)

1. Go to [vercel.com](https://vercel.com) and click **Add New → Project**.
2. Import **`NalinaHM/startupSarthi`**.
3. Under **Environment Variables**, add:
   - `GEMINI_API_KEY` = your Gemini API key
   - `VITE_GEMINI_MODEL` = `gemini-2.5-flash`
4. Click **Deploy**.
5. Your app is now live (e.g. `https://startupsarthi.vercel.app`) with serverless API protection!
