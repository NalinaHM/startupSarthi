## 🎯 Why StartupSarthi?

Thousands of aspiring entrepreneurs in India have strong business ideas but struggle to start due to **lack of initial capital**, confusion around **bank loan paperwork**, and fear of **debt traps**.

**StartupSarthi** solves this as a mobile-first, installable app (PWA + Android Play Store-ready) that turns any idea into a complete **low-capital launch & funding blueprint**:

---

## ✨ Key Features

- 💸 **Low / Zero-Capital Launch Planner**: Enter your real starting savings (even `₹0` or `< ₹25,000`) to get a Lean MVP budget breakdown (`Must-Have` vs. `Can-Wait`), zero-cost tool shortcuts (WhatsApp Business, UPI, Free Udyam), and a 30-day zero-debt action plan.
- 🧮 **Offline Smart Govt Subsidy & EMI Calculator**: Calculates your exact **PMEGP subsidy (15%–35%)** based on founder profile (General / Women / SC-ST / OBC / Rural vs. Urban), own margin needed (5%–10%), matching **PM Mudra tier** (Shishu / Kishore / Tarun / Tarun Plus), and monthly EMI — works 100% offline!
- 🏛️ **Verified Indian Govt Schemes & Interactive Checklists**: Covers **PM Mudra Yojana (PMMY)**, **PMEGP**, **Stand-Up India**, **PM SVANidhi**, **Startup India Seed Fund (SISFS)**, and **PM Vishwakarma** with direct official portal links and auto-saved document checklists.
- 📄 **Bank-Ready Detailed Project Report (DPR) Generator**: Customize applicant name, proposed business name, and address, then export a formal, white-paper **Bank Loan DPR PDF** (Cost of Project, Means of Finance, 12-Month Projections, Repayment Viability, Signature Block).
- 🌐 **Multilingual UI & AI Analysis**: Switch effortlessly between **English (`EN`)**, **Hindi (`हिन्दी`)**, and **Kannada (`ಕನ್ನಡ`)**.
- 💾 **Offline Saved Plans**: Save multiple startup plans and document checklist progress directly on your phone.
- 📊 **VC Analysis, Location Fit & Low-Budget Marketing**: Complete TAM/SAM/SOM, competitors, location hub recommendations, and zero-budget growth hacks.
- 🔒 **Production-Safe Backend Proxy**: Includes a Vercel Serverless Function (`api/analyze.js`) so your `GEMINI_API_KEY` stays completely hidden when published.

## 🚀 Local Setup

```bash
git clone https://github.com/NalinaHM/startup-validator.git
cd startup-validator
npm install
cp .env.example .env
# Add your GEMINI_API_KEY inside .env
npm run dev
```
